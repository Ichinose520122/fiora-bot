# 技能/插件删除按钮（extension-manager）

给控制台「技能」/「插件」页的**每张卡片**装一颗 🗑 删除按钮。纯插件实现，**不改应用本体**。

## 它做了什么

- 删除 = **备份式移动**，不是硬删：`<数据目录>/removed-extensions/<时间戳>-<id>/`
- 同时清掉这个扩展的开关与设置（走宿主自己的 `/api/skills/cleanup`，插件不直接改配置）
- 只允许删 `skills/` 与 `plugins/` 下的**一级子目录**：id 白名单 + 路径越界检查 + realpath 复查
- 兼容两种页面结构：应用原生卡片（原版外观 / 极光琉璃 / 深海蓝金）和「深海女仆工坊」主题的右侧详情面板

## 装上 / 关掉

- **启用**：把 `host/extension-manager-host.js` 复制到 `ui/`，并在 `ui/index.html` 的 `</head>` 前插一个带标记的 `<script>` 块；控制台刷新一次（F5）后按钮出现。
- **停用**：按标记精确摘除那一段并删掉注入脚本；刷新后按钮消失。
- 每次启动都会重新挂一遍 —— 所以**应用更新覆盖了 ui/ 之后，它会自己装回去**。

（这套"写文件 + 让页面重载"的做法和官方 `plugins/theme-installer` 完全一致：扩展系统没有前端钩子，插件碰不到页面 DOM，只能这样。）

## 卸载残留怎么清

删除某个扩展后，它的目录已进备份，配置段由页面调 `/api/skills/cleanup` 清掉。若那一步失败，它会出现在「技能」页底部的「已配置但未安装」里，用那里的「清理这些残留配置」按钮即可。

## 想彻底删掉备份

自己删 `<数据目录>/removed-extensions/` 下的文件夹（控制台 → 设置 → 数据目录里能看到数据目录位置）。
